Push a license key to every clone's Delta cache, fleet-wide. The key is sent to your phones and not stored on the server.

Push key

How it works

Separate writes to each clone's own cache:
…/Android/data/<pkg>/files/gloop/external/Internals/cache/license

Shared writes to one location all clones read:
/sdcard/Delta/Internals/Cache/license

Delta still validates the key itself — this only places it.
